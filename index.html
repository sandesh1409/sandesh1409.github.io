CASE 01
Robotics Computer Vision ROS 2

Autonomous Fruit Harvesting Robot

Japan's zero-damage quality standard for strawberries and tomatoes leaves no margin for error — a bruised fruit is unsellable. The brief was a touch-free harvesting arm that could find and pick fruit without ever contacting the fruit body itself.

  • YOLOv8 instance segmentation for fruit localization from RGB streams
  • RealSense D455 depth back-projection to recover 3D fruit centroids
  • PCA-based peduncle axis estimation to find the pick point on the stem, not the fruit
  • Eye-in-hand calibration and MoveIt 2 TF-tree transforms for camera→robot-base motion, with obstacle avoidance through foliage
ROS 2 Jazzy YOLOv8 Open3D / PCL MoveIt 2 RealSense D455
>92% success zero bruising across 300+ real harvest trials
CASE 02
LLM / GenAI RAG AWS · Azure

Production RAG & LLM Fine-Tuning Systems

A large internal document base was effectively unusable without deep institutional knowledge of where things lived. The goal was to make it queryable, accurately, by anyone on the team — without hallucinated answers.

  • Designed a modular RAG architecture connecting retrieval to the generation layer
  • Fine-tuned LLMs with QLoRA to improve task-specific performance under tight memory budgets
  • Deployed via AWS (Lambda, API Gateway, CloudFront, Amplify) and Azure OpenAI, with DynamoDB for state
  • Shipped as an in-house chatbot used in production, not a proof-of-concept demo
LangChain HuggingFace PEFT / QLoRA AWS Azure OpenAI
Prod-deployed cut document search time across large corporate knowledge base
CASE 03
Speech AI On-device ML Personal project

Local Wake-Word Detection System

A self-directed build: a fully local, privacy-preserving voice assistant wake-word pipeline with zero cloud dependency, trained and running entirely on a MacBook M4 Pro.

  • Custom wake-word model trained locally end-to-end with openWakeWord
  • Synthetic training data generated with Kokoro-82M and Qwen3-TTS across a widened voice/speed grid
  • Two-venv architecture isolating the TTS and training pipelines across three coordinated notebooks
  • Real-time evaluation pipeline for live microphone testing, with ONNX export for deployment
openWakeWord Kokoro-82M Qwen3-TTS ONNX
0.986 ROC-AUC running fully on-device, no cloud round-trip
